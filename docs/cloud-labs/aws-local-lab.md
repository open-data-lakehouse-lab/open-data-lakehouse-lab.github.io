# AWS Local Lab

This repository serves as a validation area for AWS-oriented patterns and tools in a local environment.

Candidates for local emulation:

- **Floci AWS**: For cloud resource emulation.
- **MiniStack**: For lightweight AWS service mocks.
- **Moto**: For mocking AWS services in Python tests.
- **ElasticMQ**: For SQS emulation.
- **S3Mock**: For S3 emulation.
