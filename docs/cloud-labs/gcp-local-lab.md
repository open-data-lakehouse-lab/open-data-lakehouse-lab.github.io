# GCP Local Lab

This repository serves as a validation area for GCP-oriented patterns and tools in a local environment.

Candidates for local emulation:

- **localgcp**: For Google Cloud Platform emulation.
- **fake-gcs-server**: For Google Cloud Storage emulation.
- **BigQuery Emulator**: For BigQuery local testing.
- **Cloud Spanner Emulator**: For Cloud Spanner emulation.
- **Firebase Emulator Suite**: For various GCP services.
