# Local Development

To develop for the Open Data Lakehouse Lab locally, follow these steps:

1.  **Prerequisites:**
    - Docker and Docker Compose.
    - Node.js (for documentation).
    - Python 3.9+.

2.  **Setting up the Documentation:**
    ```bash
    npm install
    npm start
    ```

3.  **Running Local Labs:**
    The local lab environments are located in:
    - `azure-local-lab`
    - `aws-local-lab`
    - `gcp-local-lab`

    Concrete commands and configuration will be added to each repository as they are implemented. You may also need the `infrastructure` repository for shared IaC components.
