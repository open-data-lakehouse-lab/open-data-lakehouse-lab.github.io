# Repository Map

The Open Data Lakehouse Lab is organized across several repositories:

- [lab](https://github.com/open-data-lakehouse-lab/lab): Central governance, coordination and ADRs.
- [open-data-lakehouse-lab.github.io](https://github.com/open-data-lakehouse-lab/open-data-lakehouse-lab.github.io): Documentation website (this one).
- [infrastructure](https://github.com/open-data-lakehouse-lab/infrastructure): IaC for local and cloud environments.
- [datasets-catalog](https://github.com/open-data-lakehouse-lab/datasets-catalog): Catalog of public datasets and metadata.
- [ingestion](https://github.com/open-data-lakehouse-lab/ingestion): Ingestion scripts and connectors.
- [transformation](https://github.com/open-data-lakehouse-lab/transformation): Data transformation models (SQL/Python).
- [dashboards](https://github.com/open-data-lakehouse-lab/dashboards): Visualization and BI dashboards.
- [api](https://github.com/open-data-lakehouse-lab/api): Analytics API.
- [web](https://github.com/open-data-lakehouse-lab/web): Web Portal.
- [azure-local-lab](https://github.com/open-data-lakehouse-lab/azure-local-lab): Azure-oriented local lab environment.
- [aws-local-lab](https://github.com/open-data-lakehouse-lab/aws-local-lab): AWS-oriented local lab environment.
- [gcp-local-lab](https://github.com/open-data-lakehouse-lab/gcp-local-lab): GCP-oriented local lab environment.
- [orchestration](https://github.com/open-data-lakehouse-lab/orchestration): Workflow orchestration.
- [quality](https://github.com/open-data-lakehouse-lab/quality): Data quality and testing.
- [observability](https://github.com/open-data-lakehouse-lab/observability): Monitoring and observability.
