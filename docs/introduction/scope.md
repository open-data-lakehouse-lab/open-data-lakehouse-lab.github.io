# Project Scope

The scope of the Open Data Lakehouse Lab includes:

- **Local Cloud Environments**: Validation areas for cloud services (storage, compute, identity) locally, prioritizing Azure for the MVP, then AWS and GCP.
- **Data Ingestion**: Pipelines to fetch and store public open datasets, focusing initially on weather data.
- **Lakehouse Architecture**: Implementation of Medallion architecture (Landing/Raw, Bronze, Silver, Gold).
- **Data Governance**: Metadata management, data quality checks, and open-source licensing.
- **Analytics & BI**: Integration with visualization tools, query engines, and analytics APIs.
- **Documentation**: A documentation-first approach using Docusaurus and Mermaid diagrams.
