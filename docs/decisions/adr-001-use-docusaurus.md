# ADR 001: Use Docusaurus for Documentation

## Status

Accepted

## Context

We need a tool to manage and publish the project documentation. It should support Markdown, be easy to use, and allow for a professional-looking site.

## Decision

We decided to use Docusaurus v3 as the documentation framework.

## Consequences

- Documentation is written in Markdown/MDX.
- Easy integration with GitHub Pages.
- Support for search, versioning (if needed), and customization.
