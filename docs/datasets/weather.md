# Weather Dataset

Weather data is the initial focus for the MVP. The specific dataset is currently being selected and evaluated in the `datasets-catalog` repository.

Candidate sources include:

- **AEMET**: Spanish State Meteorological Agency.
- **Meteocat**: Meteorological Service of Catalonia.
- **datos.gob.es**: Spanish Open Data Portal.
- **Dades Obertes Generalitat**: Catalonia Open Data Portal.
- **data.europa.eu**: Official portal for European data.
- **Eurostat**: European statistical office.

The selection process remains open until the `datasets-catalog` repository evaluation is complete.
